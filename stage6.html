Этап 6: Изменение координат

Преобразование GPS-координат в локальную систему.

Выполняемые задачи:
  • Геодезические расчёты
  • Преобразование координат
  • Повышение точности

GPS выдаёт широту и долготу в градусах, а дрону для управления нужны метры относительно точки старта. Для небольшого района используют локальную систему ENU (восток–север–вверх). Для высокой точности применяют библиотеку pyproj (UTM).

Демонстрация

Код (Python)

import math
R = 6378137.0                               # радиус Земли, м

def gps_to_local(lat, lon, lat0, lon0):
    x = R * math.radians(lon - lon0) * math.cos(math.radians(lat0))  # восток
    y = R * math.radians(lat - lat0)                                 # север
    return x, y

print(gps_to_local(51.1712, 71.4530, 51.1694, 71.4491))
