Этап 4: Обнаружение объектов

Распознавание объектов камерой БПЛА нейросетью YOLOv8, определение координат.

Выполняемые задачи:
  • Распознавание объектов с помощью камеры
  • Применение нейронной сети YOLOv8
  • Определение координат объекта
  • Обнаружение препятствий

YOLOv8 за один проход по кадру выдаёт рамки, классы и уверенность. Объекты с уверенностью ниже порога отбрасываются. Пиксельные координаты центра рамки затем переводятся в метры/GPS (этап 6).

Демонстрация

Код (Python)

from ultralytics import YOLO

model = YOLO("yolov8n.pt")
res = model(frame, conf=0.5)[0]            # порог уверенности
for box in res.boxes:
    cls  = model.names[int(box.cls)]
    x, y, w, h = box.xywh[0].tolist()      # центр и размеры рамки (пиксели)
    print(cls, float(box.conf), x, y)
