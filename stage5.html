Этап 5: Создание карты

Картирование окружающей среды: SLAM, 2D/3D карта, дрон с траекторией.

Выполняемые задачи:
  • Применить алгоритм SLAM
  • Создать 2D/3D карту
  • Вставить объекты на карту (дрон с траекторией)

SLAM одновременно определяет положение дрона и строит карту. Здесь показана упрощённая карта занятости (occupancy grid): дрон облетает область «змейкой», а ячейки в радиусе датчика становятся свободными или занятыми.

Демонстрация

Код (Python)

import numpy as np
grid = -np.ones((H, W))                    # -1 неизвестно, 0 свободно, 1 занято

def update(grid, pos, world, r=2):
    x, y = pos
    for j in range(y-r, y+r+1):
        for i in range(x-r, x+r+1):
            if 0 <= j < H and 0 <= i < W:
                grid[j, i] = world[j, i]   # результат измерения дальности
    return grid
