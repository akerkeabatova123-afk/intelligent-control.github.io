Этап 1: Подготовка данных и программное обеспечение

Сбор данных с камер и датчиков, фильтрация шума, нормализация.

Выполняемые задачи:
  • Сбор данных с камер и датчиков
  • Применение датасета
  • Удаление шума (фильтрация)
  • Нормализация данных
  • Обработка изображений (OpenCV)
  • Коррекция данных GPS и ошибок

Поток кадров с камеры и показания GPS/датчиков приходят «грязными»: с шумом и разным масштабом. Поэтому сначала данные очищают (фильтр), приводят к единому диапазону (нормализация) и только потом передают нейросетям.

Демонстрация

Код (Python)

import cv2, numpy as np

cap = cv2.VideoCapture(0)              # поток данных с камеры
ok, frame = cap.read()
frame = cv2.GaussianBlur(frame, (5, 5), 0)          # удаление шума
frame = cv2.resize(frame, (640, 640))
x = frame.astype(np.float32) / 255.0                # нормализация 0..1

def moving_avg(a, w=5):                              # фильтр для GPS/датчиков
    return np.convolve(a, np.ones(w) / w, mode="same")
