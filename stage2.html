Этап 2: Генерация траектории

Расчёт эффективного маршрута БПЛА: круговая, восьмёрка, произвольная.

Выполняемые задачи:
  • Выбрать район полёта
  • Применить алгоритмы ИИ / планирования
  • Учесть препятствия
  • Определить оптимальный путь

Траектория задаётся набором точек. Для круга и восьмёрки используются параметрические уравнения; для произвольной — набор путевых точек. Точки, попавшие в зону препятствия, смещаются наружу. На практике для поиска пути применяют A*, RRT или обучение с подкреплением.

import numpy as np

def circle(r, n=200):
    a = np.linspace(0, 2*np.pi, n)
    return np.c_[r*np.cos(a), r*np.sin(a)]

def eight(r, n=200):                                  # лемниската / «восьмёрка»
    a = np.linspace(0, 2*np.pi, n)
    return np.c_[r*np.sin(a), r*np.sin(a)*np.cos(a)]

def avoid(path, obstacles, margin=5):
    for cx, cy, R in obstacles:
        d = np.hypot(path[:,0]-cx, path[:,1]-cy)
        near = d < R + margin
        path[near] = [cx, cy] + (path[near]-[cx, cy]) / d[near,None] * (R+margin)
    return path
