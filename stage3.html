Этап 3: Управление полётом

Управление движением дрона в реальном времени: PID или PPO.

Выполняемые задачи:
  • Применить алгоритм PID (или PPO)
  • Коррекция скорости и направления
  • Маневрирование

PID-регулятор считает ошибку между заданным и фактическим значением: P реагирует на текущую ошибку, I накапливает прошлую, D предсказывает будущую. Подберите коэффициенты в демонстрации — посмотрите на перерегулирование и скорость установления. PPO — алгоритм обучения с подкреплением, который может заменить ручной подбор.

Демонстрация

Код (Python)

class PID:
    def __init__(self, kp, ki, kd):
        self.kp, self.ki, self.kd = kp, ki, kd
        self.i = 0.0; self.prev = 0.0

    def update(self, target, value, dt):
        e = target - value
        self.i += e * dt
        d = (e - self.prev) / dt
        self.prev = e
        return self.kp*e + self.ki*self.i + self.kd*d

pid = PID(4, 1, 1.5)
